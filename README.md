# C++17 五子棋

提供 **Win32 原生图形界面**（Windows）和控制台两种入口，共用相同的规则与 AI 核心。游戏为 15×15 棋盘，黑棋先手；横、竖、两条斜线任意方向连成五个或以上棋子获胜。棋盘下满且无人获胜时为平局。

PvC 中玩家执黑先手，电脑执白后手。AI 使用五层 Minimax 搜索和 Alpha-Beta 剪枝，并依据进攻/防守启发式排序候选点；局面评分通过四个方向的五格窗口识别连五、活四/眠四、活三/眠三等棋型（含跳棋型），优先完成必胜棋并阻挡对手的直接胜点。无需第三方运行库。

## 三人四子棋

三人四子棋提供两种玩法，均为 15×15 棋盘，任意方向连成四个或以上棋子获胜，满盘无胜者为平局：

- **三人同屏**：三名玩家轮流执黑、白、红棋。
- **三人人机**：玩家执黑，电脑1执白、电脑2执红。两台电脑各自为战，只追求自己获胜，会阻挡任何一方（包括另一台电脑）的直接胜点，不会互相配合。

### 三人同屏附加规则

- **活三**：三颗同色棋子连续排列，且两端均为空位，下一手可在任意一端成四。
- **死三**：三颗同色棋子只差一手成四，但只有唯一成四点（例如一端被封住，或跳三）。
- 轮到你时，只要**其他任一玩家**仍有死三或活三，你的落子就不得形成**新的活三**；违反时该落子无效，需要重新选择。
- 如果这手直接连成四子获胜，则不受此限制。
- 该规则只在三人同屏模式启用；三人人机模式不使用。

## 图形界面（Windows）

使用 Windows 自带的 Win32 API 和 GDI 绘制，不需要额外安装 UI 库。

### 直接双击启动

构建完成后，项目根目录会生成 **`五子棋.exe`**。以后直接在文件资源管理器中双击这个文件即可打开游戏窗口，不必打开命令行，也不需要另外安装 C++ 运行库。

首次生成或重新生成程序时，开发者可在项目根目录运行以下构建命令：

```powershell
cmake -S . -B build
cmake --build build --config Release
```

生成后双击项目根目录的 `五子棋.exe` 即可游玩。控制台版仍单独保留为 `gomoku.exe`。

### 操作方式

- 主菜单点击 **双人对战 PvP**、**人机对战 PvC**、**三人四子棋 同屏** 或 **三人四子棋 人机** 开始；也可点退出。
- 在棋盘交叉点单击落子，PvP 双方轮流操作；PvC 中电脑在玩家落子后自动回应。
- 三人同屏由三名玩家共用鼠标，按黑 → 白 → 红顺序轮流落子；顶部会显示同屏附加规则，若落子会形成被禁止的活三，状态栏会提示并拒绝该手。三人人机中玩家执黑，落子后电脑1（白棋）和电脑2（红棋）依次回应。
- 右侧显示当前回合、状态和落子记录；棋谱格式为“手数 棋色 坐标”，例如 `01 黑 H8`。电脑落子会标注“电脑”；鼠标在记录框内滚轮可浏览较早棋步。三人局的记录使用“黑 / 白 / 红”区分棋色。
- 已占用交叉点不能重复落子。
- 点击“悔棋”可撤回操作：PvP 和三人同屏撤回最近一颗棋子；PvC 和三人人机撤回玩家与所有电脑最近这一整轮。对局结束后也可以悔棋；棋谱会随悔棋同步回退，新局开始后记录清空。
- 对局过程中可点击“重新开始”“返回主菜单”或“退出游戏”。对局结束后可以再来一局或返回菜单。
- 按 **Esc** 从对局返回菜单；在主菜单按 Esc 关闭窗口。点击标题栏关闭按钮也可退出。
- 拖动窗口边缘可以调整大小，棋盘布局会随窗口重新绘制。

## 控制台版

原控制台目标 `gomoku` 保留，支持 Windows 和 POSIX 终端：

```bash
g++ -std=c++17 -O2 -Wall -Wextra -Wpedantic -Iinclude src/main.cpp src/game.cpp src/three_player.cpp src/three_player_ai.cpp -o gomoku
./gomoku
```

Windows MinGW：

```powershell
g++ -std=c++17 -O2 -Wall -Wextra -Wpedantic -Iinclude src/main.cpp src/game.cpp src/three_player.cpp src/three_player_ai.cpp -o gomoku.exe
.\gomoku.exe
```

输入主菜单数字后按 Enter：`1` 为 PvP，`2` 为 PvC，`3` 为三人同屏，`4` 为三人人机，`5` 为退出。落子使用“行 列”格式，如 `8 8`。三人同屏会显示并执行“他人已有死三/活三时不可再成活三”的附加规则；三人人机不受此限制。等待输入时按 Esc 可退出。

## 构建与运行测试

```bash
cmake -S . -B build
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure
```

核心测试不依赖第三方框架，覆盖落子边界、输入解析、四方向胜负、回合切换、AI 必胜/阻挡与满盘处理。三人四子棋另有独立测试，覆盖三人轮换、四方向四连、五连及以上、非法落子、满盘平局、同屏活三限制（含死三触发与标准模式不启用），以及电脑的必胜、阻挡下一家、阻挡真人与另一台电脑、优先自己获胜等行为。非 Windows 平台不会创建 Win32 GUI 目标，控制台版和核心测试仍可照常构建。
